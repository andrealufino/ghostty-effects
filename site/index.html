Ghostty Effects

Quiet cursor and status shaders for Ghostty, with a CLI to manage them and a live preview in the browser.

Try them live View on GitHub

Why these

Quiet on purpose

Effects meant to stay on all day: a soft trail, a faint line highlight, a hairline ring. Nothing that competes with the text.

Light and dark

Every effect is tuned to show on both kinds of theme, and follows Ghostty when it switches.

Status at a glance

Two effects show what Claude Code is doing in each tab, one how your last long command ended.

gfx

Switch effects, variants and colours from the command line. It never writes into your dotfiles, checks a shader compiles before Ghostty loads it, and backs up what it changes.

The effects

They stack, and some come in variants. Each one is a plain Ghostty custom-shader, so it also works without gfx.

Install

The shaders need Ghostty 1.4 or newer; gfx needs macOS and python3, and brew install glslang is recommended.

zsh
git clone https://github.com/andrealufino/ghostty-effects.git
ghostty-effects/bin/gfx install
gfx add focus-line glide        # pick a couple to start with

Clone it wherever you like and leave it there: Ghostty loads the shaders from the clone, so a git pull updates them. gfx is linked into ~/.local/bin.

Then gfx variant spotlight wide, gfx color #9ccfd8, gfx claude on for the Claude Code effects, and gfx help for the rest. The README covers everything, including using the shaders by hand on Linux.
